- `gwi-mcp` checks the local paths a tool caller chooses before reading or writing them (#45): the `text_path` and `values_path` sources of the Drive write tools and `output_file` on the Gmail and Drive read tools. A path must resolve, after symlinks and `..`, inside an allowed directory (default: the server's working directory and the system temp directory; set `mcp.allowed_paths` in `settings.json` to change it), and credential locations such as `~/.ssh` and `~/.gwi` are always refused. This differs from omni-dev, which accepts any path.
